## Project Commit Phases

1. Initial commit with the RetinaFace basic module and ResNet50.
2. Implementation of RetinaFace with ONNX Runtime and MobileNetV3.
3. Implementation of the MiVOLO module and testing with the official body+face detector using native YOLOv8x.
4. Finished the RF-DETR module for body detection and completed testing with the basic pipeline.
   <br>    4.1. The basic pipeline allows the integration of two different modules: one for age estimation and another for face detection.
5. Creation of the advanced pipeline.
   <br>    5.1. The advanced pipeline introduces a data bifurcation process, enabling the MiVOLO age estimator to be fed with body crops generated by RT-DETR and face crops generated by RetinaFace, resulting in more accurate predictions.
   <br>    5.2. RetinaFace now performs face detection on body crops instead of the entire frame, improving efficiency and reducing computational cost.
6. Creation of the advanced pipeline benchmarking  (FPS, MAE, VRAM_MB, MODEL_SIZE_MB)
    <br>    6.1. I added a moving average to the age estimation updating trying to fix the visual oscilations
    <br>    6.2. Had to change the advanced pipeline and make the main loop a function so it could be imported on the evaluation scripts
    <br>    6.3. Added a save_video bool variable so you can disable the saving of the videos for big benchmarks
7. Creation of the basic pipeline benchmarking  (FPS, MAE, VRAM_MB)
    <br>    7.1. The former modular pipeline
8. Implementation of RT-DETR
9. Changing the resize from MiVOLO and RetinaFace. Now the resizing is done with the model's own methods and its implemented as a function from the detector/estimator class
 <br>    9.1. To implement this changes its necessary to have the official repositories dowloaded on the projects folder
10. Made a just MiVOLO (only_face) pipeline and a benchmark with new metrics (RMSE, CS5%, CS10%,MAE/Model_size,FPS/MB, FPS/MAE) to test UTKFace datatset
